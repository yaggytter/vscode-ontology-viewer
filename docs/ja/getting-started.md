# はじめに

## インストール

VS Code Marketplace から **Ontology Viewer** をインストールします（`.vsix` ファイルを直接渡された場合はそちらから）。

## サンプルを開く

コマンドパレット（`Cmd+Shift+P` / `Ctrl+Shift+P`）から **「Ontology Viewer: サンプルオントロジーを作成...」** を実行し、いずれかを選びます。

| サンプル | 内容 |
| --- | --- |
| まちの共同菜園 | 小規模なクラス階層、逆関係、インスタンス |
| 道具の貸し借り | 逆関係、対称関係、推移関係、関数的プロパティ |
| フィールド調査ノート | カタログ型レコードと型付きリテラル |
| 地域サービス | OWL クラスの代わりに SKOS で組んだ概念体系 |
| 港の朝市 | アイコン、色、カーディナリティ、関係属性 |
| 都市モビリティ拠点 | 複数領域をつなぐ中規模の運用オントロジー |
| 地域イベント（RDF/XML） | オリジナルの表示専用サンプルと「Turtle に変換」の流れ |
| 自転車パーツの互換性 | LLM が推測せずに問い合わせて答えられる OWL の事実（GraphRAG） |
| 物流用語集（英日） | 検索語の展開と用語の正規化に使う、英日 2 言語の SKOS 用語集 |
| 来歴付きデータカタログ | 数値の出どころを示して答えるための DCAT + PROV-O |
| 研究知識グラフ | `sameAs` で組織をまたいで統合した schema.org のエンティティ |
| 配送オペレーション（OWL） | 配送サンプルを OWL で書いたもの。2つのスタイルの比較用 |
| 街角カフェの注文（Object Ontology） | 入門用の Object Ontology。オブジェクト型、リンク、アクション |
| 配送オペレーション（Object Ontology） | 荷物の遅延対応で、アクションを AI エージェントのツールとして使う |
| 工場保全（Object Ontology） | センサーの警報からリンクをたどって作業指示を起票する |
| サポートデスク（Object Ontology） | 検証ルールを、エージェントが行う返金のガードレールにする |

もちろん、お手持ちの `.ttl` ファイルを開くだけでも構いません。特別な準備は不要です。Object Ontology のファイルは拡張子を `.oont.yaml` にしてください。詳しくは[はじめての Object Ontology](tutorial-5-object-ontology.md)で説明しています。

## 図を開く

オントロジーファイルにフォーカスがある状態で:

- **macOS**: `Cmd+Alt+O`
- **Windows/Linux**: `Ctrl+Alt+O`

または、エディタ右上のプレビューアイコンをクリックするか、コマンドパレットから **「Ontology Viewer: 図でプレビューを開く」** を実行します。

図はファイルの隣に**スキーマビュー**（既定）で開きます。クラスごとに1ノード、関係ごとに1エッジで表示し、データ型プロパティは独立ノードにせず各クラスに折りたたんで表示します。ツールバーの **Schema / Triples** 切替で、生のトリプルグラフ（主語・述語・目的語をすべてノードにした表示）に切り替えることもできます。ファイルの中身を正確に確認したいときに便利です。

> **なぜ `Cmd+Shift+O` ではないのか？** それは VS Code 標準の「シンボルへ移動（Go to Symbol in Editor）」で、大きな `.ttl` ファイルほど本当に便利な機能だからです。この拡張機能はあえてこのキーを奪いません。

## 基本操作を試す

1. **ノードをドラッグ** — 位置は次回この図を開いたときも記憶されています。
2. **ノードをクリック** — 右側に Inspector が開き、名前・説明・プロパティ・関係が表示されます（点線の枠があるノードのみ編集可能です）。
   凡例には同系色の意味が、選択したエンティティには接続グループが表示されます。
3. **Inspector の名前欄を編集** — 新しい値を入力して Enter を押すか、フォーカスを外します。`.ttl` ファイルが更新されるのを確認してください。同じパネルの「+ Property」ボタンでプロパティを追加したり、ドロップダウンから既存プロパティの型を変更したりできます。
4. **ノードをダブルクリック**するとフォーカスモードに入り、そのノードの周辺以外が減光されます。背景をクリックすると解除されます。
5. わざと壊してみましょう。エディタに不正な Turtle を入力してみてください。図は直前の正常な状態を表示し続け、エラー箇所には波線が表示されます。
