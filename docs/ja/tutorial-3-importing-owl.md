# チュートリアル3: 既存の .owl ファイルを取り込む

世の中に出回っている OWL ファイルの多くは、Turtle ではなく RDF/XML（`.owl` や `.rdf`）形式です。本拡張機能はこれらを表示できますが、書き戻しは Turtle のみに対応しています（[対応形式](format-support.md) 参照）。ここでは推奨のワークフローを紹介します。

## 1. ファイルを開く

（**「Ontology Viewer: サンプルオントロジーを作成...」** から）`samples/community-event.rdf`、またはお手持ちの `.owl`/`.rdf` ファイルを開きます。

## 2. プレビューする

`Cmd+Alt+O` / `Ctrl+Alt+O` を押します。グラフが表示されます（このサンプルでは参加者・活動・会場と、それらの関係）。ノードをドラッグしたり、クリックして元の XML にジャンプしたりできます。

図の上部にあるバナーに注目してください: **「この形式は図では表示専用です。」**

## 3. Turtle に変換する

以下のいずれかを行います。

- バナーの **「Turtle に変換して編集」** をクリックする
- コマンドパレットから **「Ontology Viewer: 編集用に Turtle へ変換...」** を実行する

RDF/XML をパースして Turtle にシリアライズし、結果を新しい**無題（untitled）**ドキュメントとして開きます。元の `.rdf`／`.owl` ファイルが変更されることはありません。

## 4. 保存して続ける

無題のドキュメントを `.ttl` ファイルとして保存します。ここから先は通常の編集可能な Turtle ファイルです。図を開き、ノードをドラッグし、Inspector でフィールドを編集し、F2 でリネームする — [チュートリアル2](tutorial-2-editing-from-diagram.md) の内容がすべて当てはまります。

## 変換後の出力について

- よく使われる語彙（`rdf`、`rdfs`、`owl`、`xsd`、`skos`、`dcterms`、`foaf`）は、通常のプレフィックスで出力されます。
- それ以外は、元ファイルの `xmlns` 宣言から復元できる範囲でプレフィックスが付きます。
- 改行や文のまとめ方といった細かい整形は、手書きの Turtle とは見た目が異なります。XML ソースを再整形したのではなく新規に生成しているためで、これは想定通りの挙動です。
