# Support

[日本語](SUPPORT.ja.md)

Ontology Viewer is a community-maintained preview extension. Support is provided on a best-effort basis through GitHub.

## Choose the right channel

- **Something does not work:** check [Troubleshooting](docs/en/troubleshooting.md), then [open a bug report](https://github.com/yaggytter/vscode-ontology-viewer/issues/new?template=bug-report.yml).
- **You have a focused improvement:** [open a feature request](https://github.com/yaggytter/vscode-ontology-viewer/issues/new?template=feature-request.yml).
- **You found a vulnerability:** use the private process in [SECURITY.md](SECURITY.md).
- **You want to contribute:** read [CONTRIBUTING.md](CONTRIBUTING.md).

## Information that helps

Include the extension version, VS Code version, operating system, document format, reproducible steps, and relevant error messages from **View: Output**. A minimal ontology is often the fastest way to diagnose parsing or layout problems; remove proprietary or personal information before attaching it.

For a visual issue, include a screenshot, theme name, zoom level, and approximate editor-group width. For an editing issue, show the smallest before/after source example that demonstrates the problem.

## Scope

We prioritize reproducible defects, data-integrity risks, accessibility, and problems in documented formats. General ontology modeling advice, custom schema design, and support for unrelated RDF services are outside the extension's support scope.
